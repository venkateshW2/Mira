# fixtures/

Short audio clips covering the four content-type router classes (PRD §5): one-shot,
loop, track, stem — plus edge cases (mostly-silent stem, non-tonal material, field
recording). Used by tests/ and the spikes. Not committed as binary audio if large;
see .gitignore's audio-extension rules — add a fixtures-specific exception here if
small fixture WAVs need to be tracked.
